# 라인아트 뮤직비디오

한 장의 HTML이 `render(t)` 하나로 t초의 화면을 그린다. 같은 페이지가 브라우저에서는 오디오에 맞춰 재생되고, 캡처 스크립트에서는 프레임 단위로 찍혀 mp4가 된다. 상태가 없는 결정적 함수라서 어느 초로든 바로 이동해 확인할 수 있다.

예제 두 개가 실제로 완성된 결과물이다. 새 작업은 가장 가까운 예제를 복사해서 시작한다.

| 예제 | 내용 | 볼 부분 |
|---|---|---|
| `examples/sonagi.html` | 골목 → 소나기 → 카페 → 커피 김 → 창가 김서림 → 붓글씨 "난 여기 있어" | 걷기/달리기 보행, 비, 김서림 마스크, `?o=h` 로 16:9 전환 |
| `examples/hyunsim.html` | 겨울 → 촛불 → 이름 붓글씨 → 눈동자 속 봄 → 계절 타임랩스 → 하트 나무 → 크레딧 | 장면표·크로스페이드, 그려지며 등장(`reveal`), 글자→입자, 나무/계절, 벤치 커플 뒷모습 |

두 예제 모두 같은 폴더의 `song.mp3`를 읽는다 (음원은 저장소에 넣지 않았다).

## 작업 순서

1. **음원 받기.** 동영상이면 `ffmpeg -i in.mp4 -vn -c:a libmp3lame -b:a 192k song.mp3`. 동영상에 자막 트랙이 있으면 `ffmpeg -i in.mp4 -map 0:s:0 subs.srt`로 꺼내 가사 문구 참고용으로만 쓴다. **자막 시간은 믿지 않는다** (실제 노래와 6~12초 어긋난 사례가 있었다).
2. **가사 타이밍 재기.** `python3 scripts/lyrics_align.py song.mp3 work/` → `lyrics_draft.js`, `structure.txt`.
   - 뭉개진 소절은 사용자가 준 가사로 고치고, 추정해서 채운 줄은 **반드시 목록으로 사용자에게 알린다.**
   - 길게 끄는 음은 단어 시간이 부정확하다. 보컬 에너지(`structure.txt`나 vocals.wav RMS)로 무음 구간을 찾아 맞춘다.
   - 노래에 특정 단어(이름 등)가 몇 번, 언제 나오는지 찾아 하이라이트 장면의 기준점으로 쓴다.
3. **장면표 짜기.** `structure.txt`의 구간 경계(인트로/절/후렴/브릿지/아웃트로)에 장면을 맞추고, 가사 핵심어가 나오는 초에 "와" 하는 순간을 건다 (예: "촛불" → 처음으로 금색이 켜짐, "하얀 눈이 머리에" → 머리카락이 실제로 하얘짐, "봄을 기억해" → 꽃이 한꺼번에 핌). 장면표를 사용자에게 먼저 보여주고 진행한다.
4. **그리기.** 예제를 복사해 `LYRICS`, `SCENES`, 장면 함수를 바꾼다. 아래 엔진 요약 참고.
5. **확인.** `node scripts/capture.mjs stills page.html shots 5,15,33.5,...` → `python3 scripts/contact_sheet.py shots` → 시트 이미지를 직접 보고 고친다. 장면마다 최소 2장, 하이라이트 순간은 전후로 촘촘히.
6. **렌더.** `node scripts/capture.mjs video page.html song.mp3 out.mp4 30` (1080×1920 166초 기준 약 3~6분). 공유용은 `ffmpeg -i out.mp4 -c:v libx264 -preset slow -crf 23 -tune animation -c:a copy -movflags +faststart small.mp4`.
7. **전달.** mp4와 함께 재생 가능한 HTML(음원 동봉)도 준다. 확인하지 못한 것(전체 재생, 추정 가사)은 그대로 말한다.

## 엔진 요약 (예제 안에 있음)

- `pen(points, w, k, {closed, sharp, fill, col})` — 손떨림(초당 8번 바뀌는 `fb`)이 있는 펜 선. `sharp`는 모서리 유지 (문·차양·책처럼 각진 물건은 꼭 `sharp`, 안 그러면 타원처럼 뭉개진다).
- `reveal(key, u, fn)` — `fn` 안의 획들이 u(0→1)에 따라 순서대로 그려지며 나타난다. 스케치북·건물 등장에 사용.
- `person(x, y, {phase, stand, scale, dir, fem, hair, stoop, scarf, umbrella, hold, candle, wind})` — 옆모습 사람. 발이 미끄러지지 않도록 `phase = 이동거리 / (보폭 × scale)`. 손 위치를 반환하므로 손잡기·촛불 위치 계산에 쓴다.
- `benchCouple(cx, gy, s, age, lean)` — 벤치에 앉은 두 사람 뒷모습. `age` 0→1이면 머리카락이 하얘진다.
- `tree(T, x, y, sc, grow, season, t, {heart})` — 자라는 나무. season 0 봄 / 1 여름 / 2 가을 / 3 겨울 (연속값). `heart`를 주면 꽃이 하트 모양으로 핀다. 계절은 가사 키프레임 표(`SK`)로 맞춘다.
- `brushText(str, x, y, size, u, col, {glow})` — 붓글씨가 왼쪽 위에서 오른쪽 아래로 써지는 효과.
- `textPoints(str, size, step)` — 글자를 점으로 바꿈. 눈송이/별이 모여 이름이 되는 연출에 사용.
- `snow`, `petals`, `flower`, `flame`, `candle`, `frost`, `eye` — 입자·소품.
- `SCENES = [[t0, t1, fn], ...]` — 겹치는 구간은 자동 크로스페이드. `lyric(t)`가 마지막에 가사를 얹는다.
- 페이지 규약: `window.__ready`(폰트 로딩), `window.__render(t)`, 캔버스 id `c`.

## 규칙

- **가사 위치:** 9:16에서는 y≈1440~1480 (화면 75% 지점). 릴스/쇼츠 하단 캡션·오른쪽 버튼 영역을 피한다.
- **팔레트는 장면의 의미로 쓴다.** 어두운 장면에서 색 하나(금색 촛불, 분홍 봄)를 아껴 두었다가 가사의 핵심 순간에 처음 켠다.
- **같은 장면 반복 금지.** 후렴이 세 번이면 같은 무대(벤치)라도 매번 다른 변화(나이, 계절, 카메라)를 준다.
- **크레딧:** 곡이 끝난 뒤 무음을 붙여 (`ffmpeg -i src.mp3 -af apad=pad_dur=8 -t <길이> song.mp3`) 5초 이상 보여준다.
- **사람은 단순한 선화다.** 표정·손가락 디테일 대신 타이밍과 연출로 감정을 만든다고 사용자에게 미리 말한다.
- **작곡·가사 변경은 못 한다.** 녹음된 보컬을 바꿀 수단이 없다. 요청받으면 그렇게 말하고, 대신 화면(붓글씨, 별자리, 크레딧)에 넣는다.
